# 设计规范

平台无关：Web、移动端、原生都照这一套。数值以 spec/tokens 为准。

| 章节 | English | 一句话 |
| --- | --- | --- |
| [设计原则](principles.md) | Principles | 克制、每一帧都对、安静的反馈、数量多也一样好、说人话：做每一个组件、每一页都要过的五条。 |
| [颜色](color.md) | Color | 只用中性色，层级靠明度差和四级文字灰度；彩色只表达状态，一页里越少越有分量。 |
| [排版](type.md) | Typography | Text 组件 = 层级 × 色调。 |
| [间距](spacing.md) | Spacing | 16 以下每 2px 一档，只在控件内部用； |
| [布局与响应式](layout.md) | Layout | 断点按容器宽度划分，不按窗口宽度：compact 小于 720、regular 720～1199、wide 1200 及以上。 |
| [圆角与线](shape.md) | Radius & line | 圆角 6 档：4、6、8、12、16 和胶囊。 |
| [阴影与层级](elevation.md) | Elevation | 三层：卡片（只靠描边和明度差）、浮层（菜单、弹出面板、通知）、对话框。 |
| [动效](motion.md) | Motion | 八条曲线、六档时长：进入先快后慢，离开先慢后快，换位两端慢中间快。以逐帧记录为准验收。 |
| [图标](icons.md) | Icons | 统一的线性图标，线宽 1.5，颜色跟随文字。 |
| [交互质感](feel.md) | Interaction feel | 悬停、按下、拖拽、等待、打断、乐观更新。同样的功能，好用和难用就差在这些地方。 |
| [去 AI 感](no-ai.md) | No AI look | 不要星星和仙女棒图标、不要乱画分隔线、不要假数据和渐变冒充图片；对齐要量、布局不能跳、切换要有过渡。 |
| [可访问性](a11y.md) | Accessibility | 每个组件都能只用键盘操作，读屏读得出名称和状态，减少动态效果时不晃。 |
| [文案](writing.md) | Writing | 界面上的字写给用户看。 |

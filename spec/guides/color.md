# 颜色（Color）

> 只用中性色，层级靠明度差和四级文字灰度；彩色只表达状态，一页里越少越有分量。

只用中性色。层级靠背景明度差和文字四级灰度，彩色只表达状态。下面的色块显示当前主题的值，换深浅主题可以对照另一套。

## 状态色怎么用

- **正常、完成**是默认状态，不上色。
- **需要用户处理**：主文字加一个 6px 的主色圆点——全局唯一的"该你了"信号。
- **失败、被阻断**：只把关键词用危险色，不加底色块；需要图标时只用一个 14px 的图标。
- **警告**是系统级的，很少用。

**这样做**：一行里只有一个地方有颜色，而且它是用户该看的那个。

**不要**：同一个状态同时用图标、颜色、底色和文字来表达。

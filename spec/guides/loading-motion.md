# 内容加载与过渡（Loading & transitions）

> 悬停静默预取、180ms 原子提交、300/500ms 骨架防闪律与定高交叉显影，保持切换稳定不跳动。

内容切换时的闪屏和跳动，多数来自先清空再替换、以及占位尺寸与真实内容不对齐。点击下方分集与延迟档位，对比两种切换节奏。

## 常见问题

- **立刻清屏**：点击就清空原内容，哪怕 100ms 后数据就到，也会先闪一下空白。
- **骨架一闪即逝**：没有延迟宽限和最小驻留，快请求刚闪出骨架就被换掉，比不加更刺眼。
- **高度跳动**：标题折行或占位块与真实内容高度不同，导致外框和下方页面来回顶跳。
- **生硬硬切**：新内容直接覆盖原位，缺少柔和的透明度与微位移衔接。

## 五条核心时序规范

| 阶段 | 时长与阈值 | 作用 |
| --- | --- | --- |
| 悬停静默预取 | pointerenter / focusin | 在指针移向导航项到点击落定的间隙里提前准备数据。 |
| 原子提交宽限期 | ≤ 180ms | 路由切换时不立刻清屏；数据及时就绪则一次性原子提交正文与目录。 |
| 加载态延迟阈值 | 300ms | 300ms 内能返回的局部加载保留原内容，不展示转圈或骨架。 |
| 骨架最小驻留 | ≥ 500ms | 一旦露出骨架，至少驻留 500ms 再交叉替换为真实内容，避免闪烁。 |
| 定高交叉显影 | 220ms · ease.outStrong | 容器高度锁定不变，通过 opacity（0 → 1）与 4px 轻位移柔和落定。 |

## 对错对照

**这样做**：快速返回时原地稳住并直接交叉显影；超过 300ms 才淡入与真实列表逐行对齐的同构骨架并驻留满 500ms，外框高度全程不变。

**不要**：一点击立刻清空内容显示转圈和"加载中…"文字，或标题换行、占位塌陷把整页往下顶跳。

## 本官网已实装的机制

- **目录预取**：左侧目录监听 `pointerenter` 与 `focusin`，提前加载组件契约、规则与令牌表。
- **原子提交**：换页前等待最多 180ms，让新帧带齐正文与本页目录再过渡。
- **演示框记高**：已测过的演示框缓存真实高度，加载态自带 300ms 延迟，就绪后柔和淡入。
- **减少动态效果**：开启 `prefers-reduced-motion` 或 `.sn-reduce-motion` 时移除位移与缩放。

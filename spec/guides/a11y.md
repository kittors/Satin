# 可访问性（Accessibility）

> 每个组件都能只用键盘操作，读屏读得出名称和状态，减少动态效果时不晃。

每个组件都能只用键盘操作，读屏能读出名称和状态，减少动态效果时不晃。

## 键盘

| 组件 | 按键 |
| --- | --- |
| 分段控件、标签页 | ← → 切换 |
| 菜单、下拉选择、命令面板 | ↑ ↓ 移动，回车选中，Esc 关闭 |
| 滑块、数字步进 | 方向键走一格，Shift 一次走十格 |
| 弹窗、抽屉 | 焦点限制在里面，Esc 取消，关闭后焦点回到打开它的按钮 |
| 复选、单选、开关 | Tab 聚焦，空格切换 |
| 表格 | 方向键移动单元格，回车编辑，空格勾选 |

## 名称与状态

- 没有文字的按钮写 `aria-label`（或 `data-tip`，Tooltip 和读屏用同一个名称）。
- 分段控件和标签页用 `role="tab"` 和 `aria-selected`，脚本自动维护。
- Toast 用 `role="status"`，失败的用 `role="alert"`；数字变化给读屏一份完整的数字。
- 不能点的按钮用 `aria-disabled="true"` 而不是 `disabled`：还能聚焦，Tooltip 能说为什么不能点。

## 对比度

正文和背景的对比度不低于 4.5，大字不低于 3。自定义主色时，深色主题下会自动提亮到和深底的对比度不低于 4.5；主色上的字按亮度自动选黑或白。

## 减少动态效果

系统打开"减少动态效果"（`prefers-reduced-motion`）或根元素有 `.sn-reduce-motion` 时：位移、缩放、弹簧都去掉，只留必要的透明度变化；滚动跳转也不平滑滚动。

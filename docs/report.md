# Satin Web 改造报告（web-v1）

> 写给用户的最终总结：做了什么、怎么验证的、实测数据、截图与录像在哪、和改造前的有意差异、官网改了什么、哪些没做到。最后更新：2026-11-22。

## 一句话

在不破坏原有苹果式克制设计与逐帧质感的前提下，将 Satin 重构为跨 9 种主流 Web 框架（纯 HTML / React / Vue / Svelte / Solid / Preact / Angular / Next.js / Nuxt）、适配桌面与移动端 H5、自带"AI 味七根源"规范与检查器、并配套 CLI 与全量真跑示例的 UI 规范库；Web 端全量回归验收（0 非预期回归）与最终轮 AI 评测（144 份双模型对比）已全部收官，待用户确认后进入原生渲染阶段（先 MyGo 后 NSGo）。

## 做了什么

**阶段 0 · 基准与对比工具**（`scripts/parity/`）：静态（61 个嵌入区块、整页分屏、官网代表页 × 深浅 × 1440 / 768 / 390，pixelmatch 阈值 0 + DOM 与计算样式逐项）与逐帧轨迹（帧时钟统一调度、固定随机数与时间、Worker 搬进主线程、CSS 动画按帧推进，不放宽阈值）。基线只读备份在 `../Satin-baseline-20261120`（git 标签 `baseline-2026-11-20`）。

**阶段 1 · 规范**（`spec/`）：DTCG 令牌（30 种组合 3480 次取值与基线一致）、13 章设计规范、**62 个组件契约**（含新增的头像章；万级节点压测为指引页）、动效规范、**40 条去 AI 味规则（按七个根源组织）**、8 份页面配方（含手机竖/横屏完整适配）、移动端与 H5 规范。

## 官网改了什么（`site/`）

完整对照表见 [site-differences.md](site-differences.md)，核心改动如下：
- **保住原设计，仅改定位与架构**：首页浮动胶囊顶栏（`header-vs-base` 24 组除导航文字外 0 像素差异）、规范 13 章正文与本页目录逐像素对齐基线；顶栏导航重排为 `文档 · 组件 · 规范 · 配方 · 给 AI 用`，去掉所有指向展示页的入口，`/site/` 与旧 `docs.html` 自动转向新版，旧版归档 `site/legacy/`。
- **全站统一框架偏好**：支持 HTML / React / Vue / Svelte / Angular / Solid / Preact（Next.js / Nuxt 作为 React / Vue 下的环境页签），官方 Simple Icons 标志，代码块直接读取经构建和运行验收的全量示例源码；跨框架用词检查 54 页 × 9 写法 = **0 处**混词。
- **移动端设备框预览**：在"移动端与 H5"、8 份配方与手机组件示例接入 8 款 iPhone/安卓设备框（支持横竖屏、安全区底色同步、内容页半透明模糊状态栏、重画信号/Wi-Fi/电池图标），3 机型 × 横竖 × 深浅全部通过 `device-accept.mjs`（0 接缝、滚动 p95 16.7ms）。
- **窄屏排版与全站去 AI 味**：窄屏抽屉、本页目录条、手机 API 表与普通文档表改堆叠卡片排版、行内代码与数字单位防乱换行、卡片网格防 3+1 孤儿、修深色示例框 `#121212` 垫底和视频全屏 7.5px 位移；全站 94 页 1440 AI 味从 87/86 条清零至 **0 条**。

## 没做到的（如实）

- **官网截图没拍全矩阵**（决策 29）：全部官网页拍浅色桌面、深色手机 2 种组合；其余 4 种组合（深色桌面、浅/深平板、浅色手机）只拍代表页，非代表页靠嵌入区块全矩阵与全站 `docs-audit` 覆盖。
- **图标只做到了"用户自己引的按需"**（问题 12 部分解决）：`satin-ui/icons` 支持单图标按需导入；但组件内部仍通过 `data-i="name"` 查表，调用 `setup()` 会带上整张图标表（未压缩约 23.5 KB / gzip 约 8 KB）。
- **流程图 · 万级节点压测不是组件**（决策 51）：画布版压测仍是设计稿展示代码（`demo/sections/flow-stress.js`），文档页按指引页编写，63 项中 62 个组件契约齐全；是否做成正式 `createFlowCanvas` 组件待用户拍板。
- **对话的发送状态与流程图"运行"仍是演示级模拟**：对话"发送中 → 已送达"由定时器模拟；流程图缺少节点/连线改动 `onChange` 事件，"运行"进度为演示模拟。
- **若干细项限制**：视频加载失败仅加 `sn-bad` 类并发 `onError`（界面提示由业务层决定）；无限列表未内置 `role="list"/"listitem"`；图片缩略图加载态由页面加类控制；Angular 全量示例页因框架无子树 ErrorBoundary 改用全局 `ErrorHandler`（决策 54）；附件加入动效沿用原 0.88 + 上移 6px 以保基线逐帧一致；流式生成中途卸载仅专项验证了对话组件。
- **没有真机实测**：移动端基于 Chromium 手机模拟（含 CPU 4× 降速与合成手势）及 WebKit 无头模式，未在实体 iPhone / 安卓机上实测。
- **CI 未远端运行**：`.github/workflows/ci.yml` 按要求未 push，未在远端执行。

# 和改造前不一致的地方（逐条解释）

默认不允许有差异。下面每一条都是改造带来的、确认过是预期或改进的变化；效果对比工具（scripts/parity/）里能复现。

| # | 在哪 | 差异 | 为什么 | 画面 |
|---|---|---|---|---|
| 1 | Markdown 演示里"能动的 HTML"那段示例代码 | 示例代码里写的 `var(--label)` 变成 `var(--sn-label)`，代码高亮的分词跟着变 | CSS 变量统一加了前缀，示例代码演示的就是怎么用 Satin 的变量，必须跟着改；预览 iframe 里定义的变量也是新名字 | 代码块折叠在框里，静态截图逐像素一致 |
| 2 | 右键菜单 | 窗口只改高度（不改宽度）时不再收起菜单（原来只有官网嵌入模式下这样） | 库里不能有官网专用的判断；手机上地址栏伸缩、软键盘弹出只改高度，也不该把菜单关掉 | 不改窗口尺寸时无差异 |
| 3 | Markdown"能动的 HTML"预览 | 改造前预览 iframe 的高度上报和外面装监听有竞态，偶尔停在 48px；改造后修掉：外面装好监听以后，在 iframe 载完和框的尺寸变化时主动再问一次高度 | 改进 | — |
| 4 | Markdown 链接、图片地址 | `java⇥script:`、`java↵script:`（协议中间夹 Tab / 换行）、开头带控制字符的 `\u0001javascript:` 原来能过过滤，点了会执行脚本；现在按浏览器解析 URL 的规则先归一再判断，一律换成 `#` | 安全漏洞修复（`scripts/test/md-xss.mjs`，64 条向量全部拦住） | 正常内容无差异 |
| 5 | 提示词输入框加真文件 | 视频、音频、文档这类真文件原来拿演示照片当缩略图底色，现在没有底色（显示占位底色） | 组件里不能带演示数据（问题 7） | 展示页的附件菜单走演示数据，无差异 |
| 6 | 没设 `data-radius` 的页面（没引 theme-boot） | 按钮、输入框按胶囊圆角显示（改造前按钮是 8px 圆角、输入框内边距按非胶囊） | 设计稿的默认就是胶囊（2026-11-18 用户确认）；没引 theme-boot 的页面原来和设计稿不一样 | 设计页、官网都带 data-radius，画面不变 |
| 7 | 官网文档（site/next-docs、旧站）的代码、参数表、开始页、主题页 | 文字内容改了：类名带 sn- 前缀、导入改成 satin-ui 的包路径和新 API（createXxx、setup、enhance）、开始页按 npm 包重写 | 原来的写法在新包里用不了（/satin/kit-*.js 已经不存在）| 只有文档文字（代码块、表格、正文）变，版式、演示、浮层不变；由 docs-audit 和抽查对比图确认 |
| 8 | 通知（notify）在 480 宽以下 | 通知的容器占满宽度、两边留 12（原来固定 360 宽、右边 24，390 宽的手机上左边只剩 6px） | 手机适配（阶段 4） | 手机宽度下没有通知时看不出来（容器是空的）；DOM 快照里容器宽度不同 |
| 9 | 触屏设备（pointer: coarse / hover: none） | 悬停样式不生效、悬停才出现的操作一直显示、输入框 16px、右键菜单能长按、抽屉能滑动关闭 | 手机适配（阶段 4） | 用鼠标的设备上完全不变（效果对比都是鼠标环境） |

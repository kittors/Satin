# 官网和基线的有意差异

> 基线：只读备份 `../Satin-baseline-20261120`（git 标签 `baseline-2026-11-20`）。这里只记**有意**的改动和原因；不在这里的差异都算回归，要修。
> 页面：首页 `site/next.html`、文档 `site/next-docs.html`。旧版官网挪进 `site/legacy/`（`index.html`、`docs.html`、`home.js`、`docs.js`）原样保留，只做了类名前缀和路径，官网任何地方都不链接它。

- 屏幕用全屏网页 / App 内嵌网页的尺寸，不是 Safari 再扣掉工具栏的 viewport。
- 安全区由设备框自己让（11-21 下午改）：iframe 放在安全区以内（竖屏上面让出状态栏 / 灵动岛、下面让出横条；横屏 iPhone 两侧对称让、安卓只让开孔那一侧），让出来的那一圈涂成页面自己的底色（从 iframe 里读 body / html 的背景色）。原来的做法是给 iframe 地址加 `&safe=`、等库的 `theme-boot.js` 读参数写变量——要库配合，而且只对用了库样式的页面有效；现在任何页面放进来，内容都不会压进灵动岛、横条底下。iframe 里 `env(safe-area-inset-*)` 是 0，页面看到的视口 = 屏幕减安全区（和真机上内容区一样大）。
- 状态栏（竖屏）：时间、信号、Wi-Fi、电量，正文色、不加底；iPhone 时间在灵动岛左边那块的正中、图标在右边那块（时间 9:41，17px 半粗），SE 时间居中、信号在左、电量在右（12px），安卓时间靠左、图标靠右（12:30，14px）。横屏不画（iPhone 横屏系统也不显示）。图形是通用的线条 / 色块，不用厂商图标。
- 外观：中性深色细边框（10px；SE 上下 72px），阴影用 `--sn-e1`；灵动岛 126 × 37、底部横条 134 × 5、安卓手势条 108 × 4、打孔 12px、Home 键 46px 细圈。不画高光、渐变，不照抄厂商渲染图。
- 缩放：整台手机连同上面的切换条任何时候都完整在视口里。钉在右边的：页面在最顶上时的原位、往下滚钉住的位置，取靠下的那个算可用高度；宽度 = 整块宽度减去左栏至少要的 560 和间距，最宽 420（横屏 480）。放在正文里的（示例框、配方预览里那台）：按滚到它所在的卡片（卡片顶在顶栏下面 24px）时能用的高度算，卡片顶上的控制条、设备框自己的上下边距都扣掉。
- 钉在右边还是放到标题下面："移动端与 H5"页右边放下设备框以后，左边讲解那栏至少留 560px（主会话 16:25 要求，横屏时手机约 540 宽、左栏被挤到 430 左右）；留不够、设备框又会窄过 260（竖屏）/ 400（横屏）时，设备框挪到标题下面整行放（正文、设备框都不超过平常正文的 832 宽）。1440 × 900：竖屏、横屏都钉在右边（横屏约 416 宽）；1280、1366：横屏在标题下面；1081–1200 左右竖屏也在标题下面。
- 安全区上下两条的颜色：页面上 / 下边贴着固定或吸附的栏（顶栏、贴底操作栏）时用这条栏的颜色，像真机上栏的底色一直延伸到屏幕边；没有就是页面底色（16:25 主会话指出白色操作栏和下面那条页面底色之间有接缝）。

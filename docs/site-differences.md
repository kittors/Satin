# 官网和基线的有意差异

> 基线：只读备份 `../Satin-baseline-20261120`（git 标签 `baseline-2026-11-20`）。这里只记**有意**的改动和原因；不在这里的差异都算回归，要修。
> 页面：首页 `site/next.html`、文档 `site/next-docs.html`。旧版官网挪进 `site/legacy/`（`index.html`、`docs.html`、`home.js`、`docs.js`）原样保留，只做了类名前缀和路径，官网任何地方都不链接它。

## 全站

| 位置 | 基线 | 现在 | 为什么 |
|---|---|---|---|
| 定位文案（首页标题第二行、副标题、页脚一句话、`<title>`、description） | 每一帧都打磨过的界面组件库 | 每一帧都打磨过的前端规范库；给 AI 用，React、Vue 等主流框架、桌面、移动端和 H5 | 用户要求的新定位 |
| 顶栏导航（首页、文档页） | 文档 · 组件 · 规范 · 主题 · 展示页 | 文档 · 组件 · 规范 · 配方 · 给 AI 用 | 用户要求；每项进到同名的专属页面（组件 → 组件总览，配方 → 配方总览，给 AI 用 → 安装与用法），不再跳回首页某一节；不露出展示页 |
| 顶栏其余元素 | — | 和基线一样（首页：搜索图标、深浅切换、开始使用，往下滚收成浮岛；文档页：搜索框"搜索组件 ⌘K"、主题调整、深浅切换） | 用户要求只改导航文字 |
| 窄屏（≤ 860px）顶栏 | 首页：同桌面缩小；文档页：左边"打开目录"按钮 + 遮罩 | logo、搜索、菜单；菜单打开整屏高的抽屉（自带头部和关闭按钮，分区清楚，底部单行框架选择器 + 外观） | 用户要求 |
| 框架偏好 | 无（代码只有 HTML / JS） | 全站一个框架偏好（官方标志），只在文档侧栏顶上、代码块头部（手机在抽屉底部）；代码取自 `examples/` | 用户要求，见 `docs/site-ia.md` |
| 演示框右上角"在展示页里打开"（↗） | 有，链到 `../index.html#区块` | 去掉；框顶那一行（设置项所在行）高度不变 | 用户要求官网不出现指向展示页的入口 |
| `/site/`（目录）和旧的文档地址 `site/docs.html` | 打开旧版首页（里面还有"展示页"入口）/ 旧版文档页 | 转到新版首页 `next.html` / 新版文档 `next-docs.html`，网址里的查询参数和 # 后面的部分原样带过去（旧地址 `#/c/button`、`#/guide/…` 新版都有）；旧版页面挪到 `site/legacy/` 保留 | 主会话决定（2026-11-21）：官网入口只有新版 |
| 页脚 | 4 列（开始、组件、规范、资源）；资源里有"组件展示页" | 5 列（文档、组件、规范、配方、给 AI 用），和顶栏同五组 | 信息架构和顶栏一致；不露出展示页 |

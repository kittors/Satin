# Security Policy

## Supported Versions

Security updates are provided for the latest published minor release of `satin-ui` and `satin-cli`.

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability (such as XSS in `satin-ui/markdown`, `satin-ui/chat`, or unsafe CLI behavior), please **do not** open a public GitHub issue.

Instead, report it privately via [GitHub Security Advisories](https://github.com/kittors/Satin/security/advisories/new) with:

- A clear description of the issue and affected package / subpath
- Minimal reproduction steps or payload
- Potential impact and any suggested remediation

We will acknowledge receipt within 72 hours and coordinate a fix and disclosure timeline.

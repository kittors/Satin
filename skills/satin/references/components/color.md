# 颜色 · 04 号 §1

> 组件 id：`color`　分组：基础

只用中性色。层级靠背景明度差和文字四级灰度表达，不靠彩色；彩色只用在危险、成功、警告这类语义上。色块显示当前主题的值，切换主题可以对照另一套。

**只用中性色：层级靠背景明度差和四级文字灰度表达；彩色只用在危险、成功、警告这类状态上。强调色就是正文色（浅色主题黑、深色主题白），开关、复选框、进度、焦点都用它。**

## 相近的组件

- `type`：排版里的四级文字色就是这里的 label 系列。
- `elevation`：层级靠明度差，阴影见阴影与层级。

## 样式定制

| 变量 | 作用 | 默认值 |
|---|---|---|
| `--sn-canvas / --sn-raised / --sn-sunken`（全局令牌） | 页面底色 / 卡片、面板 / 凹下去的区域 | #f5f5f7 / #fff / #e8e8ed |
| `--sn-label / --sn-label2 / --sn-label3 / --sn-label-off`（全局令牌） | 四级文字：正文 / 次要 / 说明 / 不可用 | #1d1d1f / #424245 / #6e6e73 / #aeaeb2 |
| `--sn-fill-hover / --sn-fill-active`（全局令牌） | 悬停、按下时叠的一层 | 黑 4% / 黑 7% |
| `--sn-line / --sn-line-control`（全局令牌） | 分隔、描边 / 输入框这类控件的边 | 黑 8% / 黑 14% |
| `--sn-accent`（全局令牌） | 强调色（就是正文色） | #1d1d1f |
| `--sn-danger / --sn-success / --sn-warning`（全局令牌） | 状态色：只表达危险、成功、警告 | #d92d20 / #248a3d / #b25000 |
| `--sn-focus / --sn-ring`（全局令牌） | 键盘焦点的边 / 外面一圈 | 黑 40% / 黑 7% |

## 设计规范

- 这样做：页面只写令牌，不写色值：换深色主题时一起换。
- 这样做：层级拉开靠明度：卡片比页面亮一点，凹下去的区域暗一点。
- 这样做：彩色只在说状态的时候出现：删除、失败用危险色，完成用成功色。
- 不要：在样式里写死 #xxxxxx、rgb()。（规则 `color-token`）
- 不要：用品牌色、彩色图标、彩色徽章装饰。（规则 `status-color`）
- 不要：渐变底、渐变文字。（规则 `no-gradient`）

## 验收要点

- **强调色等于主文字色**：开关、复选框、进度、焦点都用黑（浅色）或白（深色），不用品牌色。
- **禁止**：琥珀色等彩色品牌色、彩色图标、彩色状态徽章、左侧竖条、渐变文字。

## 规则

- **强调色等于主文字色**：开关、复选框、进度、焦点都用黑（浅色）或白（深色），不用品牌色。
- **禁止**：琥珀色等彩色品牌色、彩色图标、彩色状态徽章、左侧竖条、渐变文字。

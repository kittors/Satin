# 间距 · Spacing

> 组件 id：`spacing`　分组：基础

16 以下每 2px 一档，只在控件内部用（图标和字之间、控件内边距）；再往上逐级放大，用在组件之间、区块之间。越相关越近：组和组之间至少是组内的两倍。页面和组件只写语义令牌（--gap-*、--pad-*），换密度时它们一起换档。

**16 以下每 2px 一档，只在控件内部用；再往上逐级放大，用在组件之间、区块之间。越相关越近：组和组之间至少是组内的两倍。页面和组件只写语义令牌，换密度时它们一起换档。**

## 相近的组件

- `layout`：间距管元素之间多远；布局管整页怎么排、怎么随宽度变。
- `space`：圆角与线管边框和圆角。

## 样式定制

| 变量 | 作用 | 默认值 |
|---|---|---|
| `--sn-sp-2 … --sn-sp-80`（全局令牌） | 刻度：2、4、6、8、10、12、14、16、20、24、28、32、40、48、64、80 | 同名像素 |
| `--sn-gap-tight / --sn-gap-inline / --sn-gap-stack`（全局令牌） | 紧挨着 / 同一行并排 / 上下堆叠 | 4 / 8 / 12 |
| `--sn-gap-group / --sn-gap-section`（全局令牌） | 组和组 / 区块和区块 | 16 / 32 |
| `--sn-pad-card / --sn-pad-panel / --sn-pad-page`（全局令牌） | 卡片 / 面板 / 页面的内边距 | 16 / 24 / 32 |

## 设计规范

- 这样做：组件之间写语义令牌（--sn-gap-*、--sn-pad-*），不写数字。
- 这样做：组和组之间至少是组内的两倍（8 和 16、12 和 24）。
- 这样做：标题离下面的内容比离上面的近。
- 不要：写刻度外的值（13px、18px）又不写原因（/* sp-ok: … */）。（规则 `spacing-scale`）
- 不要：到处画分隔线代替留白。（规则 `no-decorative-divider`）

## 验收要点

- 只用刻度上的值。不在刻度上的（给图标让位的内边距、负外边距居中、字的视觉居中）要在那一行写清原因（/* sp-ok: … */）；node scripts/lint-spacing.mjs 检查全部样式。
- 越相关越近：组和组之间至少是组内的两倍（8 和 16、12 和 24）；标题离它下面的内容比离上面的近。
- 控件内部用 2～14；组件之间从 8 起；区块之间 24 起。
- 语义令牌（标准密度）：--gap-tight 4、--gap-inline 8、--gap-stack 12、--gap-group 16、--gap-section 32；--pad-card 16、--pad-panel 24、--pad-page 32。
- 三档密度：紧凑（表格、后台、工具）、标准（默认）、宽松（阅读、欢迎页）。容器上写 data-density，里面的语义令牌一起换档，刻度不变。

## 规则

- 只用刻度上的值。不在刻度上的（给图标让位的内边距、负外边距居中、字的视觉居中）要在那一行写清原因（`/* sp-ok: … */`）；`node scripts/lint-spacing.mjs` 检查全部样式。
- 越相关越近：组和组之间至少是组内的两倍（8 和 16、12 和 24）；标题离它下面的内容比离上面的近。
- 控件内部用 2～14；组件之间从 8 起；区块之间 24 起。
- 语义令牌（标准密度）：`--gap-tight` 4、`--gap-inline` 8、`--gap-stack` 12、`--gap-group` 16、`--gap-section` 32；`--pad-card` 16、`--pad-panel` 24、`--pad-page` 32。

# 阴影与层级 · 04 号 §6

> 组件 id：`elevation`　分组：基础

三层：卡片（只靠描边和明度差）、浮层（菜单、Popover、通知）、对话框。卡片悬停时不上浮、不加阴影，只叠一层悬停填充。Tooltip 和 Toast 不在这三层里，用反色底，一眼能和页面内容分开。

**三层：卡片（只靠描边和明度差）、浮层（菜单、弹出面板、通知）、对话框。卡片悬停时不上浮、不加阴影，只叠一层悬停填充；文字提示和轻提示用反色底，一眼能和页面内容分开。**

## 相近的组件

- `space`：圆角与线管描边、圆角。
- `popover`：弹出面板是浮层那一层的典型。
- `dialog`：对话框是最上面那一层。

## 样式定制

| 变量 | 作用 | 默认值 |
|---|---|---|
| `--sn-e1`（全局令牌） | 浮层：菜单、弹出面板、通知 | 0 8px 24px 黑 10% + 1px 描边 |
| `--sn-e2`（全局令牌） | 对话框 | 0 24px 64px 黑 16% + 1px 描边 |
| `--sn-menu-shadow`（全局令牌） | 菜单（再加一道内侧高光） | 同 e1 一档 |
| `--sn-tip-bg / --sn-tip-fg`（全局令牌） | 文字提示、轻提示的反色底和字 | #1d1d1f / 白 |
| `--sn-scrim`（全局令牌） | 对话框、抽屉后面的遮罩 | 黑 30% |

## 设计规范

- 这样做：卡片只用描边和明度差；能单独操作的对象才用卡片。
- 这样做：浮在内容上面的东西（菜单、浮层）才用阴影、毛玻璃。
- 不要：彩色投影、发光。（规则 `no-colored-shadow`）
- 不要：页面里的卡片、侧栏用毛玻璃。（规则 `glass-only-floating`）
- 不要：卡片悬停时上浮、加大阴影。（规则 `motion-props`）

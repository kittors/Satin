# 手机和 H5

Satin 的组件在手机上照样能用；这一页是手机上要多注意的地方。库已经处理的写在"库做了什么"，写页面时要做的写在"你要做什么"。

## 库做了什么

| 情况 | 处理 |
|---|---|
| 触屏点完按钮一直是悬停色（iOS Safari 尤其明显） | 所有悬停样式只在有悬停的设备上生效（`@media (hover: hover)`）；鼠标设备上不变 |
| 悬停才出现的操作（表格行操作、通知的关闭、附件的移除、卡片的勾选）触屏上没法悬停 | 触屏上一直显示 |
| 刘海屏、底部横条（`viewport-fit=cover` 时） | 轻提示、通知、抽屉让开安全区（`env(safe-area-inset-*)`）；`.sn-bottom-bar` 让开底部横条 |
| 软键盘弹出时盖住贴底的操作栏（iOS 不缩小布局视口） | `setup()` 按 visualViewport 算出键盘盖住的高度，写成 `--sn-kb`；`.sn-bottom-bar` 停在键盘上面 |
| iOS 聚焦字号小于 16px 的输入框会把整页放大 | 触屏上输入框字号 16px |
| iOS 长按不发 contextmenu | 右键菜单（`data-ctx`）在触屏上长按 500ms 打开，不弹系统菜单、不选中文字 |
| 抽屉在手机上只能点关闭 | 触屏上手指往右拖就能关（跟手走，拖过三成宽或甩得快就关，不然弹回） |
| 侧栏在手机上占掉一半宽度 | `createSidebar(el, { collapseBelow: 720 })`：布局窄于 720 时自动收成图标栏 |
| 小图标按钮点不中 | `sn-tap`：样子不变，能点到的范围至少 44×44 |
| `100vh` 在手机上包括地址栏 | 骨架类用 `100dvh` |

## 你要做什么

1. `<meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover">`；不要 `maximum-scale=1`（禁止放大不利于看不清的人）。
2. 单栏布局；字段一栏，间距 20；页面左右留 16（`.sn-page` 在窄屏上自动收）。
3. 主操作放底部 `.sn-bottom-bar`（总价 + 一个主按钮）；页面底部留出操作栏的高度。
4. 点击区至少 44×44（量的是真点得到的范围，不是看得见的框）：图标按钮加 `sn-tap`；分段控件、分页在触屏（`pointer: coarse`）下已经用透明伪元素把点击区上下扩到 44；自己的小按钮照这个写法扩（`::after { content: ""; position: absolute; inset: 50% 0 auto; height: max(100%, 44px); translate: 0 -50%; }`，按钮 `position: relative`）；挨得太近、扩不开的才把按钮换成 `sn-lg`；列表行整行可点。可点元素之间至少 8px。
5. 选择用底部抽屉或选择器，不要跳新页面再跳回来；不要用 `alert()`。
6. 不要只靠悬停给信息（Tooltip 里的内容在手机上要能点开看，或者直接写在界面上）。
7. 横向不能滚动：表格在手机上改成一行一张的列表，或放进 `.sn-tbl-sc`（自己横着滑）。
8. 深浅两套、390 宽都截图看一遍：`node <技能目录>/scripts/check.mjs dom <页面地址>` 会量 390 宽下的点击区和横向溢出。
